# 🛍️ Kurti Selling Website

A full-stack MERN e-commerce website for browsing and purchasing kurtis online.

## ✨ Features

- Browse kurtis online.
- Explore different kurti categories.
- View product details.
- Organize product information using a database.

## 💻 Tech Stack

### 🎨 Frontend
- React.js
- HTML
- CSS
- JavaScript

### ⚙️ Backend
- Node.js
- Express.js
- REST APIs
- CRUD Operations

### 🗄️ Database
- MongoDB

### 🛠️ Tools
- Visual Studio Code
- Thunder Client
- GitHub

## 📌 Project Overview

This group project focuses on developing an e-commerce platform where users can browse kurtis and explore products by category. MongoDB is used for product-related data, and backend APIs support application functionality.

## 👩‍💻 Project Experience

Developed collaboratively as part of a Full Stack Web Development internship, gaining practical exposure to frontend development, database operations, and API testing.
